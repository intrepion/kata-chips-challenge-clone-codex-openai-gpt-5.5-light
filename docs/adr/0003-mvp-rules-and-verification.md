# MVP Rules and Verification

MVP 1 will include floor, wall, chip, chip socket, exit, four colored keys and doors, water, fire, water boots, and fire boots, with no monsters yet. Level wins will show a short completion state before advancing, movement will buffer one pending direction, invalid moves will resolve as ticks, progress will persist the highest unlocked level in localStorage, basic touch directional controls will supplement keyboard input, and completion requires syntax, whitespace, Playwright behavior, and direct file-launch verification.
